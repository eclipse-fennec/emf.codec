# OpenAPI example descriptions

The files under `v3.0`, `v3.1` and `v3.2` are the examples of the OpenAPI Initiative's
"Learn OpenAPI" site, copied unchanged from
[OAI/learn.openapis.org](https://github.com/OAI/learn.openapis.org), directory `examples`,
commit `5f26927b00d5d3d10c1a1a6bbe2d9b41b4a726e7`.

They are licensed under the [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)
licence, © OpenAPI Initiative. Each `.json` file and the `.yaml` file of the same name describe the
same API; the tests load both and compare the models.
